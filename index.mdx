Quick Image Gen (QIG) integrates AI image generation natively into SillyTavern. Choose from 18 cloud and local providers, apply one of 44 style presets, let your connected Text AI write and refine prompts from the current chat scene, and deliver images inline — all without leaving the chat interface.

## What Quick Image Gen Does

QIG embeds directly in the SillyTavern sidebar and organizes every setting around the generation workflow: pick a provider, choose a prompt source, select a style, and generate. Everything else — advanced controls, contextual filters, character overrides — sits behind progressive disclosure so the panel stays usable at a glance.

## Key Capabilities

- **Multi-backend support** — 18 providers including free options (Pollinations), paid APIs (NovelAI, GPT Image, Stability AI, Replicate, Fal.ai, Together AI), and fully local backends (A1111, ComfyUI)
- **Chat-scene generation** — pulls context from selected chat messages and optionally rewrites it into an image prompt via your connected Text AI
- **Two-step prompt pipeline** — first pass distills a visual scene; second pass formats it into the chosen style
- **Batch generation** — 1–10 images per run with sequential seeds and a batch viewer
- **Auto-generation** — fires after every N AI responses with a configurable delay
- **Inject mode** — AI emits `<image>` tags inside replies; QIG extracts and generates automatically
- **Character overrides** — save per-character prompts, styles, and reference images
- **Gallery and history** — IndexedDB-backed image gallery and prompt history, both scoped to your SillyTavern account

<Steps>
  <Step title="Install the extension">
    In SillyTavern, go to **Extensions → Install from URL** and paste `https://github.com/platberlitz/sillytavern-image-gen`. See [Installation](/installation) for details.
  </Step>
  <Step title="Pick a provider">
    Open the QIG panel and complete the **Quick Setup** wizard — select a provider and paste an API key if required. See [Providers](/providers/overview) for the full list.
  </Step>
  <Step title="Choose a prompt source">
    Set **Prompt source** to `Chat scene` to generate from the current conversation, or `Manual` to type your own prompt.
  </Step>
  <Step title="Generate">
    Click **Generate** or press `Ctrl+Enter`. The result appears in the chat inline.
  </Step>
</Steps>

<Note>
  Quick Image Gen requires SillyTavern 1.14.0 or newer (extension manifest v3 and media-array support).
</Note>
