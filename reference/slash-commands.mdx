Quick Image Gen registers three slash commands that work in the SillyTavern input bar, Quick Replies, and any extension that can execute slash commands. A keyboard shortcut table follows, covering generation, gallery, and prompt history.

## Commands

### /qig

Generate an image from the current settings. Accepts an optional mode override, an optional quiet flag, and optional trailing text that becomes a one-off prompt for that single run without changing your saved settings.

| Argument | Values | Description |
|---|---|---|
| `mode` | `direct`, `palette`, `inject` | Override the generation mode for this run only. |
| `quiet` | `true` | Generate silently: saves one image to the server, posts nothing to the chat, and returns the saved image path through the pipe. |
| *(trailing text)* | any string | One-off prompt text. Overrides the active prompt for this run only. |

<Note>
`mode=inject` is not compatible with quiet mode. A prompt argument is **required** when using `quiet=true`; running `/qig quiet=true` without trailing prompt text is not valid.
</Note>

**Standard generation with a one-off prompt:**

```
/qig a close-up portrait of a knight in silver armour
```

**Force direct mode for one run:**

```
/qig mode=direct a close-up portrait of a knight in silver armour
```

**Quiet mode for use with Hopper, Quick Replies, or other extensions:**

```
/qig quiet=true a sunrise landscape over misty mountains
```

When `quiet=true` is set, QIG generates exactly one image, saves it to the server, opens no dialog, and returns the saved path so downstream commands or extensions can act on it immediately.

### /qig-auto

Show the current auto-generation state or change it. Running `/qig-auto` with no arguments prints the current state to the output without changing anything.

| Argument | Values | Description |
|---|---|---|
| `state` | `on`, `off`, `toggle` | Enable, disable, or toggle auto-generation after AI replies. |
| `every` | integer `N` | Fire after every N eligible AI replies (1–100). |
| `delay` | milliseconds | Wait this many milliseconds after the triggering reply before generating. |

**Check current state without changing it:**

```
/qig-auto
```

**Enable auto-generation and set it to fire every 3 AI replies with a 1-second delay:**

```
/qig-auto state=on every=3 delay=1000
```

**Toggle auto-generation on or off:**

```
/qig-auto state=toggle
```

---

### /qig-cancel

Cancel the active generation request. Takes no arguments. QIG releases the interface immediately and requests provider-side cancellation where supported, though remote work may continue when a provider cannot cancel an already-accepted job.

```
/qig-cancel
```

## Keyboard Shortcuts

Shortcuts fire on `keydown` and are disabled when the focused element is an `input`, `textarea`, `select`, or `contenteditable`. This prevents conflicts while you are typing in the chat input bar or any settings field.

| Shortcut | Action |
|---|---|
| `Ctrl+Enter` *(default, configurable in settings)* | Generate — runs the configured palette generation |
| `Ctrl+Shift+G` | Open gallery |
| `Ctrl+Shift+H` | Open prompt history |

The `Ctrl+Enter` generate shortcut can be reassigned in QIG settings. The gallery and history shortcuts are fixed.

## Quick Replies Examples

The `/qig` command works naturally in Quick Replies. Bind a QR button to generate a portrait with a single click:

```
/qig mode=direct a close-up portrait
```

Combine quiet mode with other extensions to pass a generated image path into a follow-up action:

```
/qig quiet=true a sunrise landscape
```

The returned path from the quiet run can be consumed by the next command in a Quick Reply sequence or by an extension such as Hopper that accepts a piped image path.
